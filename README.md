# ウパ教 - ウーパールーパー愛好団体のホームページ

ウーパールーパーを愛する団体「ウパ教」の公式ホームページです。

## 📋 ページ構成

### 1. ヘッダー
- **ロゴエリア**：団体のロゴを表示（`logo.png`を挿入してください）
- **サイトタイトル**：「ウパ教」
- **ナビゲーション**：団体紹介とニュースへのリンク
- **デザイン**：ピンク色のグラデーション背景

### 2. 団体紹介セクション
- **タイトル**：「ウパ教について」
- **紹介画像**：団体の説明画像（`about-image.jpg`を挿入してください）
- **説明文**：2つの段落で団体の紹介や活動内容を記載
  - コンテンツはHTMLファイルを編集して自由に変更できます

### 3. ニュースセクション
- **タイトル**：「ウーパールーパーニュース"
- **ニュースカード**：3つのニュース記事を表示
  - 各カードには画像、タイトル、日付、本文を含みます
  - ホバー時にカードが浮き上がるアニメーション効果があります

### 4. フッター
- コピーライト表記

## 🎨 デザイン特徴

- **カラースキーム**：ピンク色（`#ff69b4`、`#ff1493`など）をモチーフ
- **レスポンシブデザイン**：スマートフォン、タブレット、デスクトップに対応
- **スムーズアニメーション**：ホバーエフェクトやスクロール効果
- **モダンなUI**：グラデーション、シャドウ、ボーダーを活用した洗練されたデザイン
